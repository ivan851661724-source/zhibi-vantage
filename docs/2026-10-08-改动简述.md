# 2026-10-08 改动简述 · 登录页 / 工作台 / 机会视图 UI 迭代

本轮聚焦三个界面的视觉与交互打磨，全部改动在本地 dev（样例数据演示态）逐项做过 DOM 级验证。
设计规范依据：`docs/design.md` §7 按钮 / 字号阶梯。

## 1. 登录页（login）

- **Tab 激活态对齐规范绿色按钮**：`登录/注册` 切换 Tab 激活态由「浅绿底 + 浅绿字」改为规范绿色按钮样式——`#8EF69A` 底、`#0D0D0D` 字、`9999px` 胶囊圆角（此前绿字对比度差）。
- **提交按钮 CTA 规范对齐**：字号 14.5px → 13.5px / 700，内边距 `12px 20px` → `11px 0`（全宽 CTA 规格）。
- **前置置灰态**：必填项未填完时「进入雷达台 → / 创建工作区 →」按钮 `disabled` + `opacity 50%`（注册模式额外校验品牌/工作区名）；`onSubmit` 兜底校验保留。

## 2. 工作台（材料卡片）

- **品牌名与链接两行**：`.burl` 改为块级换行显示；长链接（含跟踪参数）单行省略号截断（`nowrap + text-overflow:ellipsis`），品牌块 `min-width:0; flex:1` 保证与信号标签同行。
- **卡片降噪**：
  - 移除通用标题文本（「对手当前价格 / 竞争品牌当前价格」类 boilerplate，信号标签与价格区已覆盖其含义）；
  - 隐藏来源标签的 `tier-N` 后缀及「实抓 N 款」「LLM 价格点推算」取数方式标签（正则过滤，抽屉内溯源信息保留）；
  - 移除卡片左侧 3px 信号色边条（信号类型仍由彩色标签区分）。
- **置信标签归位**：「推算 / 已核实」从顶部行移至价格带 chip 右侧（`.mat-facts` 行内）；时间戳回到首行右端。
- **诚实条入 hero**：实查/推测/未探测三色条从正文顶部移入 hero 黑卡底部整行，去掉外框容器（裸色带 + 浅白文字深色适配）；「（展开字段清单）/（收起）」提示文字改为 `↓ / ↑` 箭头（保留 tooltip 与无障碍标签）。

## 3. 机会视图（opportunity）

- **标签配色**：正面来源标签（「品牌 · 口碑正面主题」类）文字色对齐 `.gid` 编号标签的 `#3F9C65`；负面标签保持红色语义（浅红底区分极性）。仅作用域 `.opp-src`，不影响其他页面同款 `.src-tag`。
- **隐藏原始编号**：`O-xxxxx` 原始编号标签不再渲染（新增 `GidTag` 组件；有中文方法名映射的——邻接结构 / 重要性+满意度 / 推测性痛点——仍正常显示）。
- **清除深色卡片**：分母 / 推理 / 注意事项（caveats）全部移到「机会分布 · 满意度 × 重要性」图下方，统一 `.pano-tip` 浅色纯文本样式（12.5px / `ink-soft`）；主视图与样本不足初步分支的 `.opp-denom` 深色卡片（`#1a2029`）全部移除，注意事项合并为连排段落。算法资产页的同款卡片组件不在本次范围。

## 回归修复（过程中引入并当日修复）
