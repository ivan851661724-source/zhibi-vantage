## 文档编写规范

1. **先文档后实现**：新增功能 / 改动接口前，先更新对应文档并在提交说明中引用文档章节号。
2. **一文档一主题**：文档之间用链接引用，不复制内容；发现重复时合并到源头文档。
3. **命名**：`NN-主题.md`，两位序号按创建顺序递增；文档内标题用中文，代码与标识符用英文。
4. **可证伪**：写"是什么"必须能对应到代码位置（文件路径 / 端点名）；写"怎么做"必须有验收标准。
5. **过期即删**：迁移完成后，被标记为"过渡期"的章节直接删除，不留历史包袱（历史在 git 里）。

## 项目现状速览

- **后端**：零 npm 依赖的纯 Node 服务（`app/server.js` + `routes/` 注册表），端口 3300，Docker 部署。
- **前端（迁移前）**：`app/public/` 下原生 HTML/CSS/JS 单页应用，`app.js` 约 272KB，7 个主面板。
- **迁移目标**：Next.js 前端服务（本目录 01/03 号文档定义），后端保持零依赖单体不动。
