# Design System — 知彼 Vantage

基于 Salesforest 概念 UI 风格移植，适用于竞品情报类工具产品。

> 本文档为前端设计单一事实来源，与 `web/src/app/globals.css` 的 `:root` 变量保持一致。
> 强调色（品牌绿）使用项目实际变量 `--brand` / `--brand-hi` / `--brand-dim` / `--brand-line`；
> 基础色/边框/圆角/间距/字体/阴影沿用下方设计令牌（色值与代码对齐）。任何色值调整需同步代码与本文档。

## 1. 品牌强调色（Brand Accent）

## 7. 组件规范速查 Component Patterns

### 卡片 Card
- 背景：`#FFFFFF`（普通）/ `#0D0D0D`（深色）（当前首页概览态：赛道 / 品牌检索为白色卡，雷达为深色卡；Hero 渐变暂未使用，见 §2.2）
- 圆角：`20px`
- 内边距：`24px`（普通）/ `28px`（Hero）
- 阴影：`subtle` / `medium` / `accent`

### Pill 导航 Nav（顶部）
- 容器背景：`#F0F0EE`，`border-radius: 9999px`，`padding: 4px`
- 选中态：`background: #0D0D0D`，`color: #fff`，`font-weight: 600`
- 未选中：`background: transparent`，`color: #555`，`font-weight: 400`

### 侧边栏一级菜单选中态（SideNav）
`.nav-item.on` / `.nav-item.active`（class 双支持，兼容 HTML/JS 旧写法）：

```css
.nav-item.on, .nav-item.active {
  background: #F0F0EE;                  /* 浅灰白实底，无透明度 */
  color: #04160C;                     /* 深绿黑字，保证可读 */
  font-weight: 700;
  /* 无阴影 */
}
.nav-item.on svg, .nav-item.active svg { opacity: 1; color: #04160C; }
```

> 与顶部 Pill Nav 的深色选中态（`#0D0D0D`/`#fff`）不同，侧边栏一级菜单采用浅灰白实底 + 品牌绿柔光投影。

### Chip 过滤器

## 8. 布局 Layout

```
│  Header（sticky，height: 64px，bg: #fff）        │
│  Logo ←→ Pill Nav ←→ Actions                    │
├─────────────────────────────────────────────────┤
│  Page Header（padding: 28px 36px 0）             │
│  Section Label → H1 → Filter Chips              │
├──────────────────────┬──────────┬───────────────┤
│  Hero Card (2/3)     │ Status   │               │
│  绿色渐变            │ Card     │               │
├──────────┬───────────┤ 深色     │               │
│ Brand    │ 情报中心  │          │               │
│ Search   │ Card      ├──────────┘               │
│ Card     │           │                          │

```

- 网格：`grid-template-columns: 1fr 1fr 1fr`

> 面板内容区实际内边距由布局层 `<main>` 提供：桌面 `padding:46px 54px 60px`，移动端 `24px 16px 48px`（对齐 §4.1 注释）。首页概览态卡片见 §2.2 现状说明。

## 9. 变更记录
